# Changelog

All behavior changes are documented here, newest first.

## 1.0.0 — 2026-11-16

Initial release.

**Coverage:**
- ADA Title III and WCAG 2.1 AA — accessibility requirements with HTML patterns and testing tools
- GDPR — consent gating, data subject rights, DPAs, international transfers
- CCPA/CPRA — opt-out implementation, data subject request window, sensitive personal information
- State privacy laws — Virginia (VCDPA), Colorado (CPA), Connecticut (CTDPA), Texas (TDPSA)
- COPPA — age gate timing, verifiable parental consent, third-party SDK configuration
- BIPA and similar biometric laws — Illinois, Texas, Washington
- GLBA Safeguards Rule — financial data access logging, encryption requirements
- HIPAA — PHI session timeout, minimum necessary principle, BAA requirement
- Fair Housing Act — algorithmic screening, disparate impact, ad targeting
- PCI DSS — hosted fields pattern, card data isolation

**Each section includes:** what the law requires, implementation patterns with code examples, real lawsuit cases with outcomes, official guidance links, and a verification checklist.
